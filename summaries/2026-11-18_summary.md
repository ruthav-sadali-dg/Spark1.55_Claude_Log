
## 20261118-001: XT7 breaker closed feedback not reaching the PLC, but HMI shows Closed

**Goal:** Explain why the HMI shows an ABB Tmax XT7 breaker as Closed when the hardwired closed-feedback signal is absent.

**Findings (from the repo):** In the Tmax UDT (`EPMS/Systems/Trip Units/Equipment Modules/ABB/Tmax/v1_0_1`), `Status/BKRSTS` reads the trip unit over Modbus (`IRUS40.0`). `Status/BKRSTSWPLC` uses BKRSTS whenever `Comms/COMMSTS` is Connected and its quality is good. It only falls back to the hardwired PLC tag `.../Diagnostics/PLC/Marshalling/<CB>/Breaker_Closed` when comms are lost. So a dead aux contact is invisible on the HMI until the Modbus link drops; then the HMI would wrongly show Open.

**Field checklist (SOP draft):** Compare BKRSTS with the PLC `Breaker_Closed` tag in the Tag Browser. Check the PLC DI LED with the breaker closed and then open. If the DI is ON when the breaker is open, an NC contact is wired instead of NO. Check that the open/closed aux contact (not the trip-signal contact) is fitted and wired. On withdrawable units, check the auxiliary connector is engaged. Check the DI common/24 V supply, fuse, and marshalling terminations. If an Ekip Signalling output relay is used, check that it is programmed for "CB closed" and that its aux power is present. Field work by qualified electricians only (arc-flash PPE / LOTO).

**Outcome:** Explanation and checklist given. Offered a discrepancy alarm (BKRSTS vs Breaker_Closed).

**Follow-up (Ekip Signalling 2K-3):** The closed feedback comes from an Ekip Signalling 2K-3 output relay, not a mechanical aux contact. Checks: confirm the trip unit detects the 2K-3 module. Confirm the 2K-3 outputs (typically O31/O32) have a signal source of CB Closed / CB status, contact NO, no delay, no latch. Make sure the config is on the 2K-3 and not on 2K-1/2K-2, and the field wiring lands on the 2K-3 terminals. The 2K outputs are dry contacts, so the PLC side must supply its 24 V through them. Use Ekip Connect to view or test output states. Aux power is very likely fine, since Modbus (Ekip Com) is working.

**Follow-up (2K-3 status page):** The trip-unit display shows the 2K-3 detected (FW 1.73). Input 1 Off, Input 2 On, Output 1 Open, Output 2 Open, with the breaker Closed. **Neither output is closed**, which confirms the closed-feedback output is not assigned or driven (a configuration issue), not a PLC or wiring fault. Input 2 being On means something live is landed on the 2K-3 input 2 terminals. Check the drawings: the PLC feedback loop may have been landed on an input instead of an output. The module page lists I/O states only; alarms are in the trip unit's alarm/diagnostics list. Exact terminal IDs come from the ABB circuit diagram or module label and the site schematics (not available to Claude).

**Follow-up (settings identical to a working XT7):** If the configuration matches, compare the **live states**, not the settings. On the working XT7 (closed), check what Output 1/2 and Input 1/2 show. (a) The working one's outputs are also Open: the closed feedback on that breaker does not come from the 2K-3 at all (likely a mechanical aux contact), so check the faulty breaker's aux contact and wiring. (b) The working one shows Output Closed: compare input states. If an output's source is tied to an input (Input 1 Off here), the missing input signal is the cause. If the inputs also match, suspect a 2K-3 module fault: swap the module with the working breaker's or replace it. The display shows the commanded output state, so PLC-side wiring cannot cause an "Open" reading there.

**Follow-up (live comparison, likely root cause found):** Good XT7 (closed): Input 1 On, Input 2 On, O31 Closed, O32 Closed. Bad XT7 (closed): **Input 1 Off**, Input 2 On, O31 Open, O32 Open. Both have O31/O32 set to Signal source = **Custom**, NO, no delay, no latch, 0 ms minimum activation time. The custom logic evidently includes Input 1 (I31), so the **missing I31 signal on the bad breaker** blocks both outputs. Next: read the Custom expression in Ekip Connect to confirm. Trace and measure the I31 field wiring on the bad breaker against the good one and the drawings. Typical sources are an aux or position (racked-in) contact or a PLC/permissive signal. Field work by a qualified electrician.
