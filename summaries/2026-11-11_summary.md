## 20261111-001: Setting up global Claude Code session logging

**Goal:** Have Claude Code document all of its work, in every directory, in a central
GitHub repo (`ruthav-sadali-dg/Spark1.55_Claude_Log`), using the same format as
`dylan-schafer-dg/Claude-Log`.

**What was done (reusable as an SOP):**
1. **Studied the reference repo.** Its format is: a global `~/.claude/CLAUDE.md` with logging
   rules, `sessions/*.jsonl` (intent/result entries per step), `summaries/{date}_summary.md`,
   `anomalies/flagged.md`, and a versioned copy of the rules in `config/CLAUDE.md`.
2. **Checked git and GitHub access in WSL.** `git config --global user.name/user.email` were set,
   and `ssh -T git@github.com` authenticated.
3. **Cloned the log repo to a fixed path:**
   `git clone git@github.com:ruthav-sadali-dg/Spark1.55_Claude_Log.git ~/Spark1.55_Claude_Log` (in WSL).
   A fixed path outside any project keeps logs out of project repos.
4. **Created the folder structure:** `sessions/`, `summaries/`, `anomalies/flagged.md`, `config/`, `README.md`.
5. **Wrote the global `CLAUDE.md`** and installed it in both places Claude Code runs from:
   `C:\Users\SadaliR\.claude\CLAUDE.md` (Windows) and `~/.claude/CLAUDE.md` (WSL).
   Changes from the reference version:
   - Log repo path and remote point to this repo.
   - Added an "Accessing the log repo" section. Windows sessions use the
     `\\wsl.localhost\Ubuntu-24.04\...` path for files and `wsl -d Ubuntu-24.04 -- git ...` for git,
     because git isn't installed on Windows.
   - A new, unrelated task in the same conversation gets a new session ID.
6. **Committed and pushed** to `main`.

**Problems and fixes:**
- *Git not found in PowerShell.* Git exists only in WSL. Ran it through `wsl`.
- *Inline bash from PowerShell returned nothing.* PowerShell 5.1 mangles nested quotes and `$`.
  Put the commands in a `.sh` file and ran `wsl -d Ubuntu-24.04 -- bash script.sh`.

**Outcome:** Logging is active for all future sessions, in both Windows and WSL. This session
was logged after the fact because the instructions didn't exist when it started.

**Possible follow-up:** Add a Claude Code `SessionEnd`/`Stop` hook to commit and push
automatically, rather than relying on Claude to remember. Install Git for Windows to
simplify the Windows-side commands.
